02 · Behaviours

All four share the crescent and face; the outer band is what each mode owns.
Endless
Free spin, e.g. LFO phase. Angle wraps in software; the matrix takes any value.
Bounded
−140°…+140° hard stops in rust, outside the face. The 8-tick ring drops out; only the top orientation marker stays.
Detents
Nine steps for filter slope, own radial band plus the rust stops. Snap lives in the value model; the angle stays float so the settle can be eased.
Arc fill
Progress arc replaces the tick ring outright — one stroked path over a static track, re-authored per frame.
